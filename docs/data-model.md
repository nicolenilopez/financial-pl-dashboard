# Data model

The exact table names, relationships, and calculation logic should be documented directly from the final Power BI project rather than inferred from screenshots.

## Checklist

- [ ] Document the synthetic data source and generation process
- [ ] Identify fact and dimension tables and their grain
- [ ] Record relationship cardinalities and filter directions
- [ ] Describe the date dimension and time filtering
- [ ] Explain actual-versus-budget calculations
- [ ] Note any disconnected tables or custom statement layouts
- [ ] Add a sanitized model diagram

**Privacy:** Remove local file paths, account or workspace details, and connection information before publication.
