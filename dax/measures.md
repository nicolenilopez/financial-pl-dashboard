# DAX measures

This file will document selected measures from the finished Power BI model. Use the original expressions from the report rather than approximate rewrites.

For each measure, include:

1. **Measure name**
2. **Business purpose**
3. **DAX expression**
4. **Formatting and sign convention**
5. **Edge cases** (for example, zero or missing budget values)

Suggested measures to document after verification:

- Revenue: Actual, Budget, Variance, Variance %
- Gross Profit: Actual, Budget, Variance, Variance %
- OPEX: Actual, Budget, Over Budget
- EBITDA: Actual, Budget, Variance, Variance %

These are documentation targets, not verified names of measures in the published report.
